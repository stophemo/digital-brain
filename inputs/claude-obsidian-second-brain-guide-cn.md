# 如何用 Claude + Obsidian 搭建一个每天自动进化的 AI 第二大脑（完整指南）

> 作者：Yarchi（X）· 中译

> 你的好想法散落在十几个地方：笔记 App、浏览器标签页、跟 Claude 聊完就关掉再也找不到的旧对话。每次坐下来干活，都得凭记忆重建上下文，大部分东西都想不起来了。
>
> 第二大脑解决的就是这个问题。

---

一个**第二大脑**，就是一个装着你所有知识的地方，Claude 坐在上面，帮你读、帮你连、帮你养。你不用每次开新会话都重新解释一遍自己——系统已经记住了。问你写过的东西，它从全局里找答案。

这就是 Andrej Karpathy 在 2026 年 4 月带火的那个 **LLM Wiki** 模式。搭一个晚上就够了。跟会腐烂的聊天记录不同，这玩意儿你用一天，它就聪明一天。

---

## 你到底在搭什么

两个工具，两个角色：

- **Obsidian** 负责存。免费笔记软件，所有内容以纯文本文件存在你自己的电脑上。笔记互相链接，久而久之形成一张图——你的想法如何连接，一眼可见。数据在你本地，不在任何公司的云上，文件永远是你的。
- **Claude** 是坐在上面的脑子。它读整个知识库，把新信息归位、跟已有内容建立链接、跨全库回答问题。

整个系统就是纯文本文件。这意味着**你不被任何 AI 锁定**。明年换个模型指过去，照样跑。因为你拥有的是脑子本身，不是工具。

---

## 第一步：安装 Claude Desktop

去 [claude.com/download](https://claude.com/download) 下载桌面版（Windows / Mac 都有）。安装，打开。

用你的 Claude 账号登录。**需要付费版**（Pro $20/月），免费版搞不定。

App 顶部有三个标签页：Chat、Cowork、Code。点 **Code** 标签。这就是 Claude Code，能真正读写你电脑上文件的版本。如果提示升级，说明你的账号还不是付费的。

---

## 第二步：安装 Obsidian，创建知识库

去 [obsidian.md](https://obsidian.md) 下载 Obsidian，免费。装好打开。

欢迎页上点 **Create new vault**。给它起个名字，比如 `brain`，选一个你电脑上的文件夹存放，点 Create。这个文件夹就是你的第二大脑。Claude 写的东西全以文本文件落在这里。

先建一条笔记感受一下：点新建笔记图标，随便打一句话，然后用两个方括号包一个词，比如 `[[目标]]`。这个方括号里的词就变成了链接。这就是 Obsidian 的核心机制——笔记指向笔记。后面 Claude 会帮你自动做这件事。

---

## 第三步：在 Obsidian 里打开连接通道

Claude 需要一个进入你知识库的门。Obsidian 通过插件来开这扇门。

在 Obsidian 里点左下角的 **设置齿轮**。菜单里点 **Community plugins** → **Turn on community plugins**。点 **Browse**，搜索 `Local REST API`，点它，然后 **Install** → **Enable**。

点已安装列表里的 **Local REST API** 打开设置。你会看到一个 **API Key**，一长串字母和数字。复制下来，下一步要用。**Obsidian 别关**——这个连接只在 App 运行时有效。

---

## 第四步：把 Claude 连到知识库

现在告诉 Claude 怎么找到那扇门。在 Claude Code 的终端里粘贴下面这行，记得把 `PASTE-YOUR-KEY-HERE` 换成你刚才复制的 Key：

```bash
claude mcp add-json obsidian-vault '{
  "type": "stdio",
  "command": "uvx",
  "args": ["mcp-obsidian"],
  "env": {
    "OBSIDIAN_API_KEY": "PASTE-YOUR-KEY-HERE",
    "OBSIDIAN_HOST": "127.0.0.1",
    "OBSIDIAN_PORT": "27124"
  }
}'
```

> ⚠️ Obsidian 显示 Key 时前面有个 "Bearer" 字样，**不要把它一起复制进去**。只复制后面的字母数字串。

这行命令通过 **MCP**（Claude 跟其他 App 通信的标准方式）把 Claude 和你的知识库接在一起。跑完之后，测试一下：

> "列出我 Obsidian 知识库里的所有文件。"

如果 Claude 把你的笔记念出来了，连接就通了。如果不行，检查 Obsidian 是不是还开着、插件是不是启用了。

---

## 第五步：把你自己装进去

现在 Claude 能读你的知识库了，但它根本不了解你。空脑壳没用。先解决这个问题——而且别自己手打，**让 Claude 来采访你**。

在 Claude 面板里粘贴这段：

```
你现在在搭建我的第二大脑。一次一个问题地采访我，帮我建立个人档案。
问这些方面：我是谁、做什么的，今年目标是什么，希望你用什么方式跟我交流，
我的优势和弱点，当前在做哪些项目。等每次回答完再问下一个。
全部完成后，把所有内容写进知识库根目录下的 CLAUDE.md 文件，用标题结构化，
这样每次会话都能自动加载。
```

回答的时候当你在跟新合伙人同步信息。越真实，脑子越懂你。完成后，打开知识库里的 `CLAUDE.md`——你的全部上下文就在那里了。**从此再也不需要重复介绍自己。**

---

## 第六步：创建项目，搭对结构

`CLAUDE.md` 是战略层。**项目**才是干活的地方。每个项目独立一个文件夹，这样 Claude 只聚焦一件事，不用管你整个人生。

让 Claude 来建。粘贴：

```
在我的知识库里创建一个叫 youtube-channel 的项目文件夹。
里面建四个子文件夹：Inputs、Process、Outputs、Feedback。
然后在这个项目文件夹里写一个 CLAUDE.md，描述这个项目是什么、唯一目标是什么、
你具体帮我做什么来达成目标。如果信息不够就采访我。
```

把 `youtube-channel` 换成你正在做的任何事。你就有了一条干净的工作流：

| 文件夹   | 用途             |
|----------|------------------|
| Inputs   | 想法和素材入口   |
| Process  | Claude 在这里干活 |
| Outputs  | 成品输出         |
| Feedback | 结果和数据反馈   |

每个领域都复制这个结构——内容创作、财务管理、客户跟进。

---

## 第七步：只打开一个项目来工作

这步是关键。**不要对着整个大知识库工作。**只打开单个项目，让 Claude 只看到那一件事。

在 Obsidian 里，点左下角的知识库名称，然后：

> Manage vaults → Open folder as a vault → 选你的项目文件夹 → Trust

现在 Claude 只读那个项目的 `CLAUDE.md`，它清楚地知道要帮你干什么，其他全忽略。

> **大知识库负责规划。单项目负责交付。**

---

## 第八步：建技能，别再重复自己

**技能（Skill）** 就是 Claude 按指令执行的保存好的工作流。凡是做过一次以上的事，都变成技能。

在项目里粘贴：

```
我想把这个变成一个可复用的技能。这是做 [某件事] 的方法，附上示例：
[粘贴你的步骤或示例]。把它保存成这个项目 skills 文件夹下的 markdown 技能文件，
起个清晰的名字，写上触发条件。
```

下次你只需要说"执行 [技能名]"，它就按你的方式立刻跑。每个重复任务建一个：写客户邮件、准备视频大纲、分类银行流水。

---

## 第九步：接入实时数据（日历、邮件）

静态笔记只占半个脑子。把实时变化的东西接进来。

加 Google 日历，在 Claude Code 终端里跑：

```bash
claude mcp add google-workspace uvx workspace-mcp --tools calendar
```

跟着弹出的 Google 登录（OAuth）走完，授权只读权限。然后你就可以说：

> "读我今天的日历，把每个会议里我承诺要做的事记到任务项目里，标记出没有明确下一步的事项。"

用同样的方式加 Gmail、Slack 或 Notion。**能只读就只读**——脑子应该读你的数据，而不是删你的数据。

---

## 第十步：上自动驾驶

技能跑顺之后，把它们定时化，让脑子自己维护自己。

在 Claude Desktop 里，打开侧边栏的 **Schedule** 标签，点 **+ New task**，填：

- **频率：** 每天早上 7:00
- **文件夹：** 你的知识库
- **提示词：**
  ```
  检查我的知识库。把 Inputs 文件夹里所有新东西归位、加链接。
  标记已经过时的笔记。给我写一个三行的摘要，说说一夜之间有什么变化。
  ```

或者直接在任何会话里告诉 Claude：

> "帮我设一个每天早上 7 点的定时任务，整理知识库并总结变化。"

你醒来的时候，脑子已经把自己整理好了。

---

## ⚠️ 一条永远别打破的规则

**靠密钥，别靠提示词。**告诉 Agent "别删这个"只是一句建议，不是安全措施。只要它技术上能删文件或发邮件，你就要假设它早晚有一天会这么做。在权限层面控制——用只读密钥、限定范围的密钥，别用嘴说。

---

## 彩蛋：用现成仓库跳过搭建

不想从零开始？开源社区已经把整套东西打包好了。在 GitHub 上搜这些：

- **claude-obsidian**（作者 AgriciDaniel）——基于 Karpathy Wiki 模式的自组织第二大脑。自动搭知识库、配好连接、内置不同角色预设（高管/构建者/创作者/研究者）。
- **obsidian-second-brain**（作者 eugeniughelbur）——自带 43 条即用命令，如 `/obsidian-save`、`/obsidian-daily`、`/obsidian-find`。跨 Claude、Codex、Gemini 通用。
- **second-brain-starter**（作者 coleam00）——采访你、生成主动助手方案，然后用纯文本文件、Python 和 Obsidian 知识库搭出来。

它们都只是文本文件和脚本。克隆一个，然后把它改造成你自己的私有版本。

---

## 十步走完，你得到了什么

**之前：** Claude 在你关掉标签页的瞬间就把你忘了。每次会话从零开始。你自己承担所有上下文，大部分你还想不起来。

**之后：** Claude 拥有了你整个人生和工作的记忆。一个装了一切的知识库、一个每次都能接着上次往下走的模型、一张在你睡觉时自动生长的知识图谱。纯文本，全归你，随便换什么模型都能跑。

同样的订阅费。完全不同的机器。

你不是在搭一套 Claude 配置。**你在建造你自己的记忆系统。**你喂它一天，它聪明一天。

---

>
