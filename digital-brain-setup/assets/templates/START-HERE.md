# 从这里开始

欢迎来到你的 Digital Brain。这里不需要复杂软件：它就是一组由你和 Agent 共同维护的
本地 Markdown 文件。

## 先认识四个地方

- `inbox/`：临时放入还没整理的资料。
- `raw/`：保存你决定收录的原始资料。
- `wiki/`：保存已经整理、可以反复使用的知识。
- `index.md`：从这里找到重要的 wiki 页面。

你的长期目标和使用偏好记录在 `profile.md`。Agent 的工作方式由
`{{RULE_FILE}}` 定义。

## 第一次使用

进入这个目录启动你的 Agent，然后选择一份文章、PDF、会议记录或个人想法：

> 收录这份资料：`/path/to/file`。先告诉我它主要讲什么，再和我确认哪些内容值得
> 放进 wiki。

Agent 会：

1. 把原件复制到 `raw/`，不移动你的源文件。
2. 和你确认真正重要的内容。
3. 创建或更新 `wiki/` 中的页面。
4. 更新 `index.md`。

你也可以先把文件放进 `inbox/`，然后说：

> 整理 inbox 里的资料，一次处理一个。

## 常用说法

- “收录这个网址，并整理成知识页面。”
- “只保存这份资料，暂时不要整理。”
- “把这段想法沉淀到我的 wiki。”
- “基于我的数字大脑解释这个问题。”
- “这条结论在 raw 里有什么依据？”
- “把这两个概念做成一页对比。”
- “整理 inbox，一次处理一个文件。”
- “检查 index 有没有漏掉重要页面。”
- “回顾我的数字大脑，建议下一步补什么知识。”

## 一个简单习惯

每周做一次小循环：

1. 清理 inbox。
2. 选一两份真正重要的资料。
3. 更新少量 wiki 页面。
4. 用一个真实问题检验这些知识是否有用。

不要追求页面数量。一个能被反复找到和使用的页面，比十个自动生成的摘要更有价值。

## 隐私提醒

这个知识库默认只保存在本地，但本地不等于加密。`raw/` 和 `profile.md` 可能包含私人
信息；把目录加入 Git remote、云盘或同步工具前，请先检查将要共享的文件。
